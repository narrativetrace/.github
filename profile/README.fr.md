**Le code est le journal.** NarrativeTrace transforme le code en exécution en récits lisibles — des traces d'exécution pour les humains qui déboguent, des traces structurelles sans valeurs pour les agents IA qui écrivent du code, et une référence qui fait échouer le build dès que le comportement dérive.

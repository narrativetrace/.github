**El código es el log.** NarrativeTrace convierte el código en ejecución en narrativas legibles: trazas de ejecución para las personas que depuran, trazas estructurales sin valores para los agentes de IA que escriben código, y una línea base que hace fallar la build cuando el comportamiento se desvía.

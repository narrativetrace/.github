# narrativetrace/.github

Valores predeterminados a nivel de organización y herramientas compartidas para los repositorios de [NarrativeTrace](https://narrativetrace.ai). Los archivos de este repositorio se aplican a todo repositorio `narrativetrace/*` que no proporcione los suyos propios.

## Contenido

| Ruta | Propósito |
|---|---|
| `profile/README.md` | El perfil de la organización que se muestra en [github.com/narrativetrace](https://github.com/narrativetrace) |
| `SECURITY.md` | Cómo reportar una vulnerabilidad, plazos de respuesta, alcance, puerto seguro |
| `CONTRIBUTING.md` | Qué aceptamos, Developer Certificate of Origin, convenciones de commits y ramas |
| `i18n/` | Herramientas de traducción: comprobaciones de estructura y desactualización para cada documento traducido |
| `.github/workflows/i18n-check.yml` | Comprobación de CI para las traducciones, reutilizable desde otros repositorios |
| `.github/rulesets/main.json` | Conjunto de reglas para la rama `main`: sin force-push, sin eliminación |

## Traducciones

Todos los documentos de este repositorio se mantienen en inglés y se traducen al chino simplificado, español, portugués de Brasil y francés. La versión en inglés es la autoritativa. Consulte [i18n/README.md](i18n/README.md) para saber cómo se comprueban y se mantienen actualizadas las traducciones.

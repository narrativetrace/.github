# narrativetrace/.github

[NarrativeTrace](https://narrativetrace.ai) 各仓库的组织级默认配置与共享工具。此处的文件适用于所有未提供自身对应文件的 `narrativetrace/*` 仓库。

## 内容

| 路径 | 用途 |
|---|---|
| `profile/README.md` | 在 [github.com/narrativetrace](https://github.com/narrativetrace) 展示的组织简介 |
| `SECURITY.md` | 如何报告漏洞、响应时限、适用范围、安全港条款 |
| `CONTRIBUTING.md` | 我们接受的贡献、Developer Certificate of Origin、提交与分支规范 |
| `i18n/` | 翻译工具：对每份翻译文档进行结构与过期检查 |
| `.github/workflows/i18n-check.yml` | 翻译的 CI 检查，可供其他仓库复用 |
| `.github/rulesets/main.json` | `main` 分支规则集：禁止强制推送、禁止删除 |

## 翻译

本仓库中的每份文档均以英文维护，并翻译为简体中文、西班牙语、巴西葡萄牙语和法语。英文版本为权威版本。关于翻译如何被检查并保持最新，请参阅 [i18n/README.md](i18n/README.md)。

# narrativetrace/.github

Organization-wide defaults and shared tooling for the [NarrativeTrace](https://narrativetrace.ai) repositories. Files here apply to every `narrativetrace/*` repository that does not provide its own.

## Contents

| Path | Purpose |
|---|---|
| `profile/README.md` | The organization profile shown at [github.com/narrativetrace](https://github.com/narrativetrace) |
| `SECURITY.md` | How to report a vulnerability, response targets, scope, safe harbor |
| `CONTRIBUTING.md` | What we accept, Developer Certificate of Origin, commit and branch conventions |
| `i18n/` | Translation tooling: structure and staleness checks for every translated document |
| `.github/workflows/i18n-check.yml` | CI check for translations, reusable from other repositories |
| `.github/rulesets/main.json` | Branch ruleset for `main`: no force-pushes, no deletion |

## Translations

Every document in this repository is maintained in English and translated into Simplified Chinese, Spanish, Brazilian Portuguese and French. English is authoritative. See [i18n/README.md](i18n/README.md) for how translations are checked and kept current.

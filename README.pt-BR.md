# narrativetrace/.github

Padrões da organização e ferramentas compartilhadas para os repositórios do [NarrativeTrace](https://narrativetrace.ai). Os arquivos deste repositório se aplicam a todo repositório `narrativetrace/*` que não forneça os seus próprios.

## Conteúdo

| Caminho | Finalidade |
|---|---|
| `profile/README.md` | O perfil da organização exibido em [github.com/narrativetrace](https://github.com/narrativetrace) |
| `SECURITY.md` | Como relatar uma vulnerabilidade, prazos de resposta, escopo, porto seguro |
| `CONTRIBUTING.md` | O que aceitamos, Developer Certificate of Origin, convenções de commits e branches |
| `i18n/` | Ferramentas de tradução: verificações de estrutura e desatualização de cada documento traduzido |
| `.github/workflows/i18n-check.yml` | Verificação de CI das traduções, reutilizável a partir de outros repositórios |
| `.github/rulesets/main.json` | Conjunto de regras da branch `main`: sem force-push, sem exclusão |

## Traduções

Todos os documentos deste repositório são mantidos em inglês e traduzidos para chinês simplificado, espanhol, português do Brasil e francês. A versão em inglês é a oficial. Consulte [i18n/README.md](i18n/README.md) para saber como as traduções são verificadas e mantidas atualizadas.
